## 1. コンセプト（実装者が迷ったらここに戻る）

**「シミュレーションを見せる」のではなく「ルールのパラメータ空間を歩かせる」。**

- 舞台はロジスティック写像 `x_{n+1} = r·x_n(1−x_n)` のみ。主人公は **r** という1つの数。
- 観客は横ドラッグで r を「歩く」。世界（粒子群）が穏やかな呼吸→2拍→4拍→カオスの霧へと**相転移**していく。
- **REVEAL 二層構造**（シリーズ署名）:
  - **NAKED**: 起動直後は UI ゼロ。現象だけ。「なんだこれ……生きてる」
  - **REVEALED**: `Tab` で HUD が浮かび、画面下に分岐図の地図が現れる — 「あなたが歩いていたのはこの地図でした」
- 品質バー（BRUSHUP-SPEC §1-1 を継承）: ①触った瞬間に因果が見える ②発見に報酬（相転移・種明かし）③証明部品（地図・周期検出・λ）④直接操作優先 ⑤どこで止めても絵になる。

### 核となる発明 — 「世界＝分岐図の生きた断面」

粒子1つ1つが**独立に同じ写像を回す**（同じ r、異なる x_i）。粒子の縦位置 = 自分の x_i。すると数学が勝手に絵を作る:

| r の領域 | 世界の見え方（創発・演出ではなく数理的必然） |
|---|---|
| r < 3.0 | 全粒子が1本の光る帯に収束 — 静かな海 |
| 3.0 – 3.449 | 帯が**2枚に裂けて**交互に脈打つ（周期2、粒子は2群に位相分離） |
| – 3.544 | 4枚 → 8枚…（周期倍分岐がそのまま見える） |
| r∞ ≈ 3.5699 以降 | 帯が霧に溶ける（カオス）。ただしバンド構造は残る |
| r ≈ 3.83 | 霧の中に突然3枚の帯が結晶する（周期3の窓） |

つまり**ライブの粒子雲が、分岐図のその r における垂直スライスそのもの**になる。REVEAL 時、下の地図と世界が同じ形をしていることが種明かしになる。

## 3. 画面構成

```
NAKED:    フルスクリーン canvas 1枚（#world）。UIなし。
REVEALED: #topbar(44px) / #main(＝#world続投＋装飾) / #side(300px) / #bottombar(44px)
          ＋ #main 下部に地図ストリップ #map（高さ 180px、canvas 別葉）
```

- REVEAL 切替は**フェード 400ms**（opacity + 数pxの浮上）。#world のシミュレーションは切替に関係なく生き続ける。
- REVEALED でも #world は #main いっぱい（地図の分だけ縦が縮む。粒子座標は相対なのでリフローで潰れないこと）。
- モバイル: viewport meta 必須。タッチ = §5 参照。#side は REVEALED 時のみ、狭幅では下からのシートでも可（実装簡略のため `overflow-y:auto` の右パネルのままでもよい）。

## 4. シミュレーション仕様

### 4-1. 粒子系（#world）
- 粒子数 `N` 初期 1200（200–4000）。各粒子: `x_i`（写像状態、初期値 = 0.001–0.999 の一様乱数）、`px_i`（横位置、固定）、明滅位相。
- 横位置: 中央寄りガウス分布＋ジッタ（機械的な等間隔にしない）。縦位置 target = `lerp(yBottom, yTop, x_i)`（上下マージン 12%）。
- **世代ティック**: `genPerSec`（初期 8、範囲 1–60）で全粒子の x_i を一斉更新。描画は rAF で縦位置を target へ `lerp 0.15/frame` — 帯の分裂・収束が「呼吸」として滑らかに見える。
- ティック時に粒子輝度をフラッシュ→減衰（脈拍）。afterimage: 毎フレーム `rgba(7,7,7,trail)` で塗り重ね（`trail` 初期 0.18、範囲 0.05–0.5）。ice→白のグラデ、粒径 1.5–2.5px。
- **r を変えても x_i はリセットしない** — 過渡状態（世界が再組織化する数世代）こそ見せ場。`R` = 再シード（全 x_i を乱数に）。
- 描画は Canvas 2D で十分（N=4000 でも 60fps 目標）。`prefers-reduced-motion`: フラッシュ振幅を半減、genPerSec 上限 12。

### 4-2. 読み出し値（hero 粒子 = index 0 の軌道から算出）
- **周期検出**: 直近 96 世代を保持し、p = 1..32 の最小の p で `|x_n − x_{n−p}| < 1e-4` が直近 3p 世代続けば `PERIOD p`。該当なし → λ で判定。
- **リアプノフ指数**: `λ = mean( ln|r(1−2x_n)| )` 直近 500 世代の移動平均。`λ > 0.01` → `CHAOS` バッジ（ice glow）、`λ < −0.01` → `STABLE`、間は `EDGE`。
- 表示: `r = 3.569946`（小数6桁・ice）／ `PERIOD 04` or `CHAOS` ／ `λ = +0.42`。

## 5. インタラクション

| 操作 | 動作 |
|---|---|
| ステージ横ドラッグ | **歩く**: `Δr = (dx / stageW) × mapWindowWidth × 0.3`。地図をズームするほど歩幅が細かくなる（ズーム＝スローウォーク） |
| `←` `→` | r を ±0.0005（`Shift` で ±0.01）。長押しリピート可 |
| ステージクリック / タップ | **擾乱**: 半径 120px 内の粒子に `x_i += (rand−0.5)×0.3`（0.001–0.999 clamp）。rouge のリップルリング 400ms。→ 周期領域では秩序が回復し、カオスでは霧に飲まれる（アトラクタの安定性を手で確かめる部品） |
| `Space` | 時間停止 / 再開（止めても絵になること — 帯の静止画は彫刻） |
| `Tab` | REVEAL 切替（`preventDefault` 必須） |
| `R` | 再シード |
| `?` | ショートカットモーダル（REVEAL レイヤー所属。NAKED 中に押したら REVEAL ごと開く） |
| `Esc` | カスケード: ①モーダル閉 → ②REVEALED なら NAKED へ → ③（最終段）`index.html` へ — EE の index は未作成なので**実装だけ用意しコメントアウト** |

- フォーカスガード（INPUT/SELECT/TEXTAREA 中は無視）を keydown 先頭に必ず入れる。
- **NAKED ヒント**: 起動 45 秒間 REVEAL されなかったら、下端中央に 8px mono `TAB — REVEAL` を opacity 0.25 でフェードイン（初回のみ。一度 REVEAL したら二度と出さない）。

## 6. 地図ストリップ（#map、REVEAL の主役）

- 分岐図を r ∈ window（初期 [2.8, 4.0]）で描画。各ピクセル列: その r で x=0.31 から 300 世代ウォームアップ → 200 世代を縦軸 x∈(0,1) にアルファ蓄積。ice 単色・ガンマ持ち上げ。
- **チャンク計算**: 1フレームあたり ~40 列、全幅 2 秒以内。計算中は左から順に「現像」されていく（この現像自体が Time Design の演出になるので、あえてプログレスバーは出さない）。
- **現在地カーソル**: rouge の縦線 1px ＋ 上端に `▾`。世界と地図が同じ縦構造（帯の枚数）であることが一目で照合できる。
- **足あと**: 訪れた r を配列に記録（世代ごとに現在 r を push、重複間引き）。地図上端 3px に gold α0.08 の蓄積ティック — 「あなたの散歩の軌跡」。`R` では消えない（COPY 対象外・リロードで消える）。
- **地図ドラッグ** = r スクラブ（即時ジャンプ）。**ホイール / ピンチ** = カーソル中心に window ズーム（最小幅 0.002、ズーム変更で再計算）。**ダブルクリック** = window リセット [2.8, 4.0]。
- window 端に範囲ラベル（mono 9px gold）: `2.800 ── 4.000`。

### 6-1. Proof オーバーレイ（サイドパネルにトグル）
- **FEIGENBAUM**（初期 OFF）: 分岐点 r₁=3.0 / r₂=3.4495 / r₃=3.5441 / r₄=3.5644 / r∞=3.56995 に gold 破線＋ラベル。隣接間隔の比 `δₙ` を並記し、末尾に `δ → 4.6692…` を ornament 書体で表示。ズームインしても線が追従（自己相似の確認ができる）。
- **WINDOW·3**（初期 OFF）: r≈3.8284 の周期3窓を gold ブラケットでマーク。

## 7. サイドパネル（.sp 構成、上から）

1. **READOUT** — r / PERIOD / λ の `.data-row`（値は `.dv.neon`）
2. **RULE** — 式 `xₙ₊₁ = r·xₙ(1−xₙ)` を ornament 書体で。r 部分だけライブ数値に差し替え（「ルールが主人公」の明文化）
3. **WALK** — ランドマークへ**歩いて**移動するボタン群（テレポート禁止。0.15 r/秒 の等速で自動走行し、道中の分岐カスケードを見せる。走行中 bottombar に `WALKING → 3.8284`、クリックか任意キーで中断）:
   `CALM 2.90` / `PULSE·2 3.20` / `PULSE·4 3.50` / `EDGE 3.5699` / `MIST 3.90` / `CRYSTAL·3 3.8284`
4. **CONTROLS** — r スライダー（window 連動）/ SPEED gen/s / PARTICLES / TRAIL
5. **PROOF** — FEIGENBAUM / WINDOW·3 トグル
6. **COPY/PASTE PARAMS** — スキーマ:
   ```json
   { "r": 3.5699, "genPerSec": 8, "particles": 1200, "trail": 0.18,
     "mapWindow": [2.8, 4.0], "revealed": true,
     "feigenbaum": false, "window3": false, "paused": false }
   ```
   PASTE は未知キー無視・既知キーのみ適用（KINETIC STAGE 規約どおり）。

## 8. 実装フェーズと完成条件

### P1 — NAKED WORLD（これだけで作品として成立させる）
粒子系＋横ドラッグ歩行＋擾乱＋Space＋R＋TABヒント。
**完成条件**: r=2.9 で1本の帯 → ドラッグで 2枚 → 4枚 → 霧、r≈3.83 通過時に3枚の結晶が**説明なしで**見える。クリック擾乱が周期領域では回復し、止めた画面がそのまま絵になる。コンソールエラーなし。

### P2 — REVEAL
HUD 二層化＋地図ストリップ（現像・カーソル・足あと・スクラブ）＋READOUT/RULE/CONTROLS＋COPY/PASTE＋ショートカットモーダル＋ESCカスケード。
**完成条件**: Tab の瞬間「世界＝地図の断面」が照合できる（帯の枚数がカーソル位置の分岐図と一致）。周期検出が 1→2→4→CHAOS→（3.83で）3 と正しく遷移。PASTE で世界が再現される。

### P3 — PROOF & POLISH
WALK ランドマーク自動走行＋地図ズーム（自己相似）＋FEIGENBAUM/WINDOW·3 オーバーレイ＋モバイルタッチ調整。
**完成条件**: EDGE 付近をズームすると入れ子の分岐が現れ、FEIGENBAUM ONで δ≈4.669 の収束が読める。CRYSTAL·3 への自動走行が「霧→突然の結晶」のドラマとして機能する。

## 9. 禁止・注意

- 外部ライブラリ不使用（Canvas 2D のみ。Three.js 化は EE-01b として別仕様）。
- 説明テキストで数学を教えない — 教えるのは地図と周期検出の**数字だけ**。理屈は WORLD TO EXPRESSION 側の役目。
- rouge の面積を増やさない（カーソルとリップルのみ）。VJ的快楽は ice の glow と afterimage で作る。
- 二次テキストは `--mute` 相当より薄くしない（既存規約）。
