# WORLD TO EXPRESSION — ブラッシュアップ記録

2026-10-20 / Asia/Tokyo

## 今回の制作

10月16日の初版レビューに沿って、現行ソースの修正を検証し、場面接続を仕上げた。作業開始時点ですでにレビュー9項目への対応コードが入っていたため、その実装を維持して検証した。今回さらに変更した作品コードは ACT01 と ACT02 の2ファイル。

- **ACT01:** 細胞から反応拡散へ変わる途中で、BELONG. と GROW. / DIVIDE. / REPEAT. が半透明で重なっていた。旧見出しをワイプで取り去ってから新見出しを開く。背景の細胞と、セル形状から開く反応拡散はその間も継承する。
- **ACT02:** 49%で233点の葉序配置を無関係な散乱点へ置き換えていた。233点を同じ座標で引き継ぎ、そこから点を分けてMANYへ整列させる。見出しが切り替わる閾値の強さは残す。
- **検証:** 分岐図の数値・描画経路チェックを追加。既存の回帰スクリプトは、99.99%へのジャンプがピクセル丸めで次章に入る問題を修正。章終端の画像は2 CSS px手前、境界の幾何比較は直接 `p=1` / `p=0` で行う。

## 検証結果

環境は Windows / headless Chrome **155.0.8059.79** / `--disable-gpu`。実機スマートフォンの検証ではない。

- [基本検証](verification/browser-report.json): 全7章×5位置×4サイズの140枚。1440×900 / 1280×800 / 768×1024 / 390×844。横方向の文書はみ出しなし、操作は画面内。HOLD、章ナビ、キーボード、リロード復元、タッチエミュレーション、PNG保存を確認。
- [詳細検証](verification/detail-report.json): 26枚、原典リンク12件すべてHTTP 200、直接タッチイベントによるスクロール、`file:` 起動を確認。
- [修正点の回帰検証](verification/revision-report.json): **91チェック合格、実行時・HTTPエラー0**。4サイズの76枚とreduced-motionリサイズ前後2枚。上記の境界、寸法、再訪、リサイズを検査。
- [分岐図の数値検証](verification/emergence-report.json): 4サイズ×2描画経路の8条件。実モデルの r≈3.10054 / 3.49982 / 3.83041 で枝数2 / 4 / 3。これはNodeによる描画バッファ・命令検証で、ブラウザの視覚検査とは別の証拠。
- [静的検証](verification/static-report.json): JavaScript構文、テキストのLF、参照ファイル、89セルの最近傍条件と面積、18反応拡散状態を確認。
- CAPTUREは1800×2400 PNG、352,624 bytes。完成ポスターの構図は保持。

全140枚は4コンタクトシートで一覧確認。修正箇所の重要画面は原寸でも確認した。各チェックの合格は記載した条件に限られ、全速度・全スクロール位置の映像的な完成度を保証するものではない。描画時間は命令発行時間、heapはJSのみで、実測FPSやGPUメモリの保証に使わない。初版に記録された約3.7ms / 約9.2MBは今回の計測値ではない。

今回のCPU描画の連続render計測では、ACT05に最大約347msのサンプルがあった。JS heapは約9.1MB。機能検査の合格とは分けて扱い、スクロールの滑らかさ・実機性能は未評価とする。

最初の制限付き実行は `ERR_NETWORK_ACCESS_DENIED` でローカルHTTP接続に失敗した。ローカルサーバーとChromeを許可された同一実行環境で起動して検証した。途中で起きた章終端のタイムアウトは上記のテスト入力の丸めによるもので、修正後の最終結果に含めていない。

**未検証:** iPhone / Android / Safari実機、実機タッチ、GPUのFPS・メモリ、長時間運用、スクリーンリーダーの実使用、全速度域の連続スクロール、人を対象とした錯視効果の評価。
