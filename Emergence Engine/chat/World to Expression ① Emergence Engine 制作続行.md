02（原点からの距離）と 04（向きのそろい具合）には種明かしのグラフ帯があるのに、03 だけ無かったので揃えました。

- **ice の線**＝網の量（直近60秒）
- **金の線**＝餌の数
- **rouge の刻み**＝拍

餌を足すと網がぐっと伸び、そのあと無駄な枝を削って細っていきます。粘菌が「経済的な網」に落ち着いていく様子が、線で見えるようになりました。音を鳴らすと拍の刻みも並びます。線・餌・拍の3種類が描かれていることは画素で確認しました。画面幅の都合でスクショは撮れていないので、Tab で開いて見てみてください。

## 3. EE-01 にも VJ パネル → 付けました

| 設定 | 何が起きるか |
|---|---|
| ON BEAT = **TICK** | 世代が拍のときだけ進む。光の帯の脈打ちが曲とぴったり合います（自動の世代送りは止まる） |
| ON BEAT = DISTURB / RESEED | どこかをかき乱す／全部の粒をばらまき直す |
| N 拍ごと | 次の名所（CALM → PULSE·2 → …）へ**歩いて**移動（仕様どおりテレポートはしない） |
| MID → / HIGH → | 世代の速さ／粒の光 |

実測：ふだんは毎秒8世代です。TICK にすると自動の世代送りは止まり、4拍で4世代進みます。MID 0.5 では毎秒15世代になります。連番PNG は 4小節（120BPM・30fps）で240枚、拍は16回入りました。
