#### この LP 特有の作り

- v=clamp((u-.04)/.90)、r は章の両端を v で線形補間、q=章の世代数×v、n=floor(q)。粒子は makeRng(1) で 1,200 個。x₀=.001+rng()*.998、横位置はアプリ seedParticle と同じ「3個の一様乱数の平均−.5」を .85 倍し、.04〜.96 の clamp と .01 の jitter。tw/tws 用も含め1粒7回の乱数消費。代表粒子 x₀=0.6268197927069851。
- 状態はその r で初期値から W+n 回 logistic を実行する純関数。ONE RULE と CALM は W=0、それ以外 W=2,500。ONE RULE の表示だけ1粒。直近4要求の結果をメモ化するが、前のスクロール位置から積分しない。Worker・世代ごとの粒子記録はない。law の関数参照を IIFE の引数へ束縛し、Node vm のグローバル参照による反復コストも避けた。
- CALM は初期雲から収束を見る。固定点 1−1/r への収束世代数は別に x₀=.31 から測る。章内の雲は各位置の固定 r で毎回計算し直すので、r を変えながら積分した軌道ではない。
- 縦位置は現在の x そのもの。アプリの実時間 lerp・残像・idle twinkle は使わない。flash=0.9^((q−n)×60/8)、reduced-motion で半分。ice→白・半径・横分布はアプリ由来。twinkle も q/8 に従う。全粒子が世代ごとに光り、金の輪の代表粒子が帯を巡る。帯ごとの手製の点滅位相は足していない。
- 周期は代表粒子の直近最大220世代を detectPeriodOf へ渡す。λ は代表粒子の直近最大500世代の lyapTerm 平均。n=0・W=0 は初期値の1項と周期未判定。HUD/data-live の読み出しと、地図の固定初期値 .31 の測定は区別する。
- 地図は起動時に3窓、各960×360。各列を mapCounts（x=.31、300助走＋200回）で計算し、濃さ min(1,(c/6)^.6) の ice を ImageData に入れ、canvasへキャッシュ。現在 r は rouge。FEIG の点線と r₁…r∞、WINDOW3 の枠を重ねる。λ 曲線は各窓の同じ960列で x=.31、2,500助走＋500回を更新後の lyapTerm で平均。表示範囲は −2〜.8、下にはみ出す負の谷は下端に点を残す。
- 雲は集合、地図は1粒の時間方向の標本。同じアトラクタの断面を示すが、助走数・初期値・標本数が違うため境目近くでは完全一致しない。本文に明記。細い窓・ゼロへの接触も960列の有限解像度であり、厳密な境界検出ではない。
- COBWEB の放物線も logistic の160分割標本。ONE RULE の階段と時系列は同じ代表粒子。CALM は直近40値、SPLIT は直近9値の階段。DIVERGE は各 r で .31 と .310001 を助走なしで80回、現在 n まで表示。縦軸 log10|Δx|、ゼロ差は表示の下限10⁻¹⁶へ置く（差の値自体は変更しない）。
- THE MAP は雲と地図の x の縦軸を共通にし、同じ断面として比較。モバイルの小図は横に並べ、低い TRACE/LAMBDA は余白を縮小。BLUEPRINT は各章の実際の r と代表 x に金の輪＋章番号のみ。引き出し線なし。通常は章末、06はr=3.83、07は3.9、08は3.6。凡例は幅で5列／3列へ段組みする。アプリと ../../index.html へのリンク。
- 音は代表粒子の x→220×2^(2x) Hz（2オクターブ）。全章の世代数を連結した整数境界を数え、飛ばした世代も1境界1音。noteAt はその境界の章・r・nから初期値を再計算する。逆走は同じ境界の同じ音を逆順に鳴らす。章をまたぐ移動も同数。1フレーム内へ等間隔に短い包絡を置き、速い移動では音が密になるが、あとから鳴り続ける待ち行列は作らない。BOW は正本同様スクロール速度で音量、ON も停止で新しい音は出ず、最後の包絡で無音。初回pointerdown・Sキー・音量・OFF・REWINDは正本の入力。

#### 検証フック・検証境界

window.__LP.goto(章,u)・manual(bool)・step(秒[,fps])・ready()・CH・stateAt(章,u)・summary()・computeTiming()・audio()。追加で measure/locate/metrics/loc/maxY、setMode、rewind/rewinding/wheel、noteAt(全章を連結した世代境界)。

stateAt は r/n/q/W/x/period/lambda/samples、points（粒子配列）、hist、flash を返す。返却値は直近4要求の内部キャッシュなので検証側で変更しない。summary は章のr範囲・世代数・両端の代表値、FEIG比、窓3の走査、収束世代数、上の参考測定表。computeTiming は起動計算ms、直近／最大状態計算ms、計算回数、粒子数・seed、地図サイズと容量。audio は mode/vol/state/motion/stepDelta/pitch/played/master/tone。
