# 02 / CREATIVE DECISIONS

## 一つの世界、一つの紙面

添付画像から NOIR / 細枠 / ワイドトラッキング / 番号付き見出し / 黄の操作状態を採る。全工程のカタログにせず、同一ステージと現在必要な操作だけが切り替わる。大画面はステージ約70〜75%、操作約25〜30%。スマホではステージが先、CONTROLS を畳む。短い横画面は自然な縦スクロールで操作を読む設計で、極端に小さく押し込まない。

工程チップは SEED→RULE、RULE→EMERGENCE、COMPARE/FREEZE→PERCEPTION、EDIT→EDIT、OUTPUT→EXPRESSION に対応。前二つは「法則を始める」から「法則が生む現象を動かす」への意味の移行。常に一つだけ aria-current=step / 黄色塗り。6シーンの正確な名前はステージ見出しに別途表示する。

## WORLD → PAPER

`take` の瞬間の表示位置をIDごとに保存し、約184ms静止、その後同じ粒子を紙面の写像位置へ移す。1150msで収束。紙は横から開き、その領域に入った粒子の色を白から墨へ反転する。KEEPで残さないIDは移動中に薄くなるが、新しいIDは作らない。文字だけを終盤に導入する。画像の差し替え・別ノイズへの再配置ではない。

reduced-motion は初期停止、転換100ms。世界の再生は明示操作で可能。編集完了後に常時揺らしたり点滅させない。ルールへの戻りでも採取素材は保持し、次のTAKEで置換されることを説明する。

## 三つの編集意思

| 構図 | KEEP | SPACE | TRACE | FOCUS強度 | 意図 |
|---|---:|---:|---:|---:|---|
| SILENCE | .30 | .72 | .00 | .15 | 左下へ小さく置く、白の余白に存在を残す |
| CURRENT | 1.00 | .04 | .85 | .25 | 黒地、実速度方向の細い線、流れを読ませる |
| SIGNAL | .85 | .04 | .18 | .80 | 紙地、注目位置に最も近い粒子一点だけ黄色 |

ポスターでは元の600点を見かけの密度のため複製しない。ライブ表示だけはトーラスの整数周期コピーでステージ全面を満たす。生成が三つの小群を作ったなら三つの小群を素材にする。密な巨大な渦の絵を保証しない。注目点は作者の指定であり視線計測ではない。

下段比較ストリップは同じhashを明記。選択中だけ現在の編集、残りは同じsnapshot＋各初期編集値。全てでIDを追跡できる。3枚は切替ボタンでもある。文字と注目位置は切替でも保持する。

## タイポグラフィと記号

EXPRESSION は紙白、COMPOSER は黄。英語に日本語の短い補助を付ける。数字は local JetBrains Mono / Consolas / monospace。日本語は local IBM Plex Sans JP / システム sans。ライセンス不明フォントを複製しない。ネットワークフォントの読込なし。

ポスター上部の小文字はpreset/採取側/seed/step/hash、下部は作品コピーと FROM / RULES / TO / WORLDS、右下の01/02/03は構図番号。装飾の座標・目盛・コーナーマーク・グリッドはない。黄は操作状態または実在する選択粒子一点。glow/bloom/neon/green なし。

参照した認識原理：近接（群れのまとまり）、共通運命（実速度とALIGN）、サイズ・濃度の重み（FOCUS）、余白・間（SPACEとKEEP）。主観的効果を数値で「証明」せず、観客自身が3枚を見比べる。

## 意図的に小さくしたもの

Canvas 2Dのみ。群れ数固定、世界は正方形トーラス、表示は画面に合わせて縮尺を変える。TYPEは二行までの見出し＋一行のサブ。履歴タイムライン・Undo・自動保存・配色自由化は追加しない。PNGとJSONに絞り、SVG/JPG/動画/外部画像/別モデル/ギャラリーは作らない。

## Claude レビュー後の判断（2026-10-26）

- 参考画像のポスターは「群れそのものが図」。v0.1 初版は世界全体を縮小して置いていたため、群れが紙面の数%しかなかった。**実データの外接矩形に合わせて拡大**し、SILENCE は左下に小さく（ax 0 / ay 1）、CURRENT は平均進行方向を水平へ回して紙面を横切らせ、SIGNAL は中央。いずれも並進・回転・拡大だけで、点の相対配置は変えない。
- CURRENT は見出しの裏まで流れが入る（参考画像 B の FLOW と同じ重ね）。文字は点の上に描く。
- FREEZE は「止まる（16%）→ 黒い紙として集まる → 焼き付けで反転」。HOLD → BUILD → BREAK → REST の BREAK を反転に置いた。

## ORDER 02 / v0.2 の判断（2026-10-27）

- ステージはデスクトップで80svh（上限880px）。1440×900では720px。スマホ縦は59svh、短い横画面は80svh。操作・出力例は必要に応じて縦スクロールする。粒子の表示面を優先し、横スクロールは発生させない。
- ZOOMは1.8を入口に、1〜3で拡大可能。世界を正方形の額に閉じ込めず、実物理と同じ周期で画面を覆う。共通ズームと左右別の円周平均カメラを明示し、COMPAREが同一条件の比較であることを補足する。
- CURRENTのSPACE=.04。SIGNALはKEEP=.85 / SPACE=.04、FRAMES=[.05,.10,.95,.87]。外接矩形へのfitと最大TRACEの予約は維持し、点の大きさ・濃さは採取時の近傍密度から作る。細長い群れの縦横比は変えず、全seedの幅70〜90%を保証する変形や切取りはしない。SILENCEは左下と大きな余白を維持。
- チップは実ボタン。①RULEと②EMERGENCEは同じ世界の調整／観察モード、見出し番号も合わせる。③PERCEPTIONはCOMPAREを開き、④⑤は素材採取後のみ有効。`.process li.done`を維持。FREEZEは④EDITへの入口であり、比較済みの証拠として扱わない。
- ALIGN操作またはRULE約8秒で、比較案内をページ滞在中一度だけ表示。工程を離れると隠し、再訪で点滅・再表示しない。直接採取したEDITには③への小さな導線を置く。
- FREEZEの紙の起点は古い正方形から「採取した表示パネル」へ。点と3stepの尾は画面位置を保って止まり、タイルのコピーは元IDへ集約。黒い紙の移動と終盤22%の焼き付けを維持する。

## v0.3 / 編集の意志を見せる

上記v0.1/v0.2の演出記述は履歴。現在はHOLD 172.5ms、TRANSFER 632.5ms、STILL 207ms、PRINT 138msで合計1150ms。印刷前線は上から下。HOLDは新しい印を足さず、採った画を固定する。

SILENCEはquiet-heading / opposite-column / low-counterweight、CURRENTはupstream / downstream / side-channel、SIGNALはabove-signal / below-signal / beside-signal。データ由来の選択で粒子を文字に合わせて移動しない。CURRENTは細い文字の墨縁で実線との競合を抑える。SIGNALは黄色点を文字から守るが、黒点と見出しの競合まで常に解消する方式ではない。最も見づらい例を[05](05_V03_REVIEW.md)に残す。

COMPARE/TAKE/FINISHをステージ上に置き、高さを削らず次の操作を見つけられるようにした。説明はdesktop11px、mobileの重要ラベル10px以上。プリセット直下に4項目リセットを一行で伝える。人間の理解・可読性評価は未実施。
