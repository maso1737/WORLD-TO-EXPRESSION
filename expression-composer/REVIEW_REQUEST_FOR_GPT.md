# レビュー依頼 — L7 EXPRESSION COMPOSER v0.2（2026-10-27）

## これは何か

WORLD TO EXPRESSION（階層的知覚・表現教材）の L7「どう表現する？」の代表作。
**Boids のルールを変える → ALIGN ON/OFF を同条件で比べる → 実在した粒子状態を採取 → 同じデータから 3 枚のポスター（SILENCE / CURRENT / SIGNAL）→ 1800×2400 PNG と再現 JSON**。

- 起動：`index.html` をダブルクリック（file:// で動く・外部依存なし）。
- 正本の仕様：`WORLD_TO_EXPRESSION_CODEX_MASTERPLAN_20261025.md`
- アートディレクションの参考：`images/`（機能はマスタープラン優先。画像の機能すべては実装しない）
- 体制：Claude Code（発注・受け入れ）→ Codex（実装）。発注書と報告は `_codex/ORDER_*.md` `REPORT_*.md`
- 検証：`docs/03_QA_REPORT.md`（Codex の自己検証＋末尾に Claude の受け入れ検査 v0.1 / v0.2）
- 見るだけで分かる証拠：`verification/claude-review/v02/sheet_*.png`（同じ seed の ALIGN ON / OFF から作った 3 枚）

## 特に見てほしいこと

1. **因果が本物か**：A/B 比較（同 seed・同歩数・ALIGN だけ違う）、採取後に絵が変わらないこと、3 枚が同一データ由来であることが、観客に**目で**伝わるか。数値（Φ）が主役を奪っていないか。
2. **体験の導線**：初めての人が 45〜90 秒で RULE → PERCEPTION（比較）→ 採取 → 編集 → 書き出し まで迷わず行けるか。v0.1 ではユーザーが比較（③）を通らずに終わった → v0.2 で工程チップを押せるようにし、1 行の誘いを足した。足りているか、うるさくないか。
3. **グラフィック品質**：参考画像に対して、画面構成・余白・タイポ・情報密度・ポスターの完成度はどこが足りないか。「科学デモ」ではなく「表現制作装置」に見えるか。
4. **ポスター 3 種の差**：SILENCE（省略）／CURRENT（流れ）／SIGNAL（一点への視線）が、意図どおり別の作品に見えるか。見出しと群れの重なりは良いか悪いか。
5. **次の一手**：v0.3 で 1〜3 件だけ足すなら何か（マスタープラン §7 PHASE 4 の「今はやらない」を踏まえて）。
