# 2026-11-09 — SP-01 HARMONIC LADDER（倍音列）

[[PLAN_SOUND_PATTERNS]] の SP-01 を実装。SP-02〜05 に続く 5 本目。前回 → [[2026-11-06]]

## できたもの
- 法則 `sound-patterns/_law/sp01_law.js`（Claude）
  - 1 つの音＝倍音 12 本（F0 220 Hz）の正弦波の和。n 本目 fₙ＝n·220·(1+dₙ)、強さ aₙ。
  - **聞こえる高さの目安＝波形の自己相関（周期の山）**。一番高い山、ほぼ同じ高さなら一番早い山（オクターブの取り違えを避ける）。
  - **間隔**＝ずれていない聞こえる倍音の番号の最大公約数 × 220。
  - **境界の読み**：FUSED（整数倍）／WOBBLE（ずれ＜目安・F0 に同期したオシロでは形が nF0|d| Hz でうねる）／POP（目安を超える＝1 本が浮き出る）。
  - 浮き出る目安は Moore, Glasberg & Peters (1986) の傾向をなぞった**仮の線**：n ≤ 6 で 2 %、上は (n/6)² 倍。聞こえる倍音＝一番強いものの 6 % 以上。
  - 音は全体の強さ（2 乗和の平方根）をそろえる＝基音を消しても音量は落ちない（高さだけを比べられる）。
- 本体 `sound-patterns/01_harmonic_ladder.html`（Claude・SP-04 の殻を使用）
  - LADDER：棒をなぞって強さを描く（ドローバー）。下の ◆ を横に引くとその倍音だけずれる（**√ 目盛りの拡大表示**：本当のずれは 3 倍音 4 % で 26 Hz＝段の間隔の 1/8 しかない）。棒の上のダイヤル＝段に対する位相（ずれた倍音だけ回る）。
  - WAVE：220 Hz に同期させた 3 周期。PROOF で 1 周期目を 2・3 周期目に重ねる（整数倍なら一致）。
  - PERIOD：周期の山 r(τ)。選ばれた山＝聞こえる高さ。
  - HEAR OUT：選んだ 1 本だけを先に鳴らす（Helmholtz の共鳴器の代わり）。全体の音はその間だけ消える。
  - AUTO 74 秒：SINE → 1 本ずつ足す → 3 倍音を 0→4 %（うねり→浮き出る）→ 戻す → HEAR OUT → 基音を消す（220 のまま）→ 4 倍以上だけ → PROOF → 偶数番だけ（440 に上がる）→ SAW。
  - 入口 `sound-patterns/index.html` の 01 を APP あり（SCROLL はまだ）に。

## 実測（Claude）
| 状態 | 聞こえる高さ（目安） | 間隔 | 読み |
|---|---|---|---|
| SINE / SAW / ODD / SL-02 | 220.0 | 220 | FUSED |
| SAW から基音を消す | **220.0** | 220（基音なし） | FUSED |
| 4〜12 倍だけ | **220.0** | 220 | FUSED |
| 偶数番だけ（2,4,6…） | **440.0** | 440 | FUSED |
| 3 倍音だけ | 660.0 | 660 | FUSED |
| SAW・3 倍音 +0.1 % / +1 % / +1.9 % | 220.0 / 220.2 / 220.3 | 220 | WOBBLE（0.66 / 6.6 / 12.5 Hz） |
| SAW・3 倍音 +2 % / +4 % / −4 % | 220.4 / 220.7 / 219.3 | 220 | POP |
| SAW・10 倍音 +8 % | 219.7 | 220 | POP（目安 5.6 %） |
| SL-02・12 倍音 +8 %（鳴っていない） | 220.0 | 220 | FUSED |

- ずらすと聞こえる高さもずれの向きに少し動く（+4 % で +0.7 Hz）。Moore ほか (1985) の「ずれた倍音が全体の高さを引っぱる」と同じ向き。
- OfflineAudioContext で書き出した音：RMS は SINE・SAW・基音なし・4 倍以上だけ・ずらしたもの全部で **0.099**（そろっている）。基音なしで 220 Hz の成分 **0**。3 倍音 +4 % で 660 Hz は 0・686.4 Hz に 0.0375（法則のゲインと一致）。ピーク最大 0.33（master 0.35 の前）。
- 実機のオシレーター 12 本の周波数・ゲインが法則の目標と一致。

## ユーザーが確かめること（聴感）
- 3 倍音をゆっくりずらして、**どのあたりで「1 本が浮き出る」か**（目安の 2 % と合うか・WOBBLE のうねりが聞こえるか）。
- **基音を消しても高さが下がらない**と聞こえるか。偶数番だけで 1 オクターブ上がるか。
- HEAR OUT の後に、溶けた音の中でその 1 本が聞こえるか。

## その2 — 解説 LP `scroll/SCROLL_HARMONIC_LP.html`（Claude）
- 11 章：問い → ONE（純音）→ STACK（1 本ずつ足す）→ REPEAT（4.55 ms で全部そろう）→ HEAR OUT（3 倍音だけ → 全体）→ WOBBLE（0→1.9 %）→ POP（→4 %）→ MISSING（基音を消す）→ SPACING（4〜12 だけ・間隔の弧）→ OCTAVE（偶数 440・3 の倍数 660）→ BLUEPRINT（立ち寄った 8 つの音の一覧）。
- 法則は sp01_law.js をそのまま読む（変更なし）。骨格は SP-04 の LP の複製。状態（強さ・ずれ・PROOF・solo）はスクロールの純関数、時間で動くのは波形とダイヤルの位相だけ。
- 本文に入れた発見：偶数番 → 3 の倍数の入れ替えの途中は 2 と 3 が両方鳴るので間隔は 220 に戻る（law の読みも 220）。
- 入口 index.html の 01 に SCROLL を足した。作りと実測は `scroll/CLAUDE.md`。
