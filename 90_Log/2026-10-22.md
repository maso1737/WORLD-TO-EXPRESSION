## EE-02 HIGHWAY の要点
- **NAKED で勝手に上演する**：ゆっくり生まれる（毎秒21歩）→ 加速 → 11,000歩前後で道 → トーラスを一周して自分の塊に衝突 → 混沌 → また別の道。約55秒ごとに次のルール（RL → LLRR → 三角 → 四角 → 渦の道）へフェードで移る。最初の操作で止まる。
- **道の検出**：先頭のアリの「p 歩ごとの移動量」が、直近 max(3p, 600) 歩ずっと同じ非ゼロベクトルなら道。座標はトーラスで折り返さない値を使う。
  - 最初は 3p だけで判定して、混沌の中の短いジグザグ（p=2）を道と誤検出した → 600歩の下限を追加。
  - Node 実測：RL は **p104・(−2,+2)** を 11,264 歩で検出（文献どおりの周期104）。LLRRRLRLRLLR は p1968 の横向きの道が 37,888 歩で出て 82,944 歩で衝突。
- **証明ストリップ**：原点からの距離のグラフ。混沌＝ギザギザで伸びない／道＝まっすぐな坂。道の区間は金、出現点は rouge。
- **ルール手術**：RULE の文字（L/R）をクリックで反転、＋−で色数を増減。**世界は止まらず走ったまま書き換わる**（色数が減ったらはみ出た色は折り返す）。
- 足あとの光は速度に応じて弱める（遅い＝明るい彗星／速い＝色の構造が見える）。

## EE-03 SLIME NETWORK の要点
- 誕生は「ばらばらの粉 → 2秒で網」。中心の胞子1点から始めると縮んで輪になる（Shift+R で見られる）。
- 6秒後から餌（金の◆）が1つずつ増え、網が餌を結ぶように組み替わる。34秒で2つ消え、40秒で別の場所に2つ。58秒で次の種へ。
- **種（SPECIES）は 32通りの総当たりで選び直した**（sa/ra/so を振って Node で描いたコンタクトシート）。見た目がはっきり違う6種：NETWORK / VEINS / LABYRINTH / HONEYCOMB / CELLS / BEADS。
  - 最初の案の LABYRINTH（sa60/ra15）と FILAMENT（so4/ss0.6）は1点や輪に潰れていた。
  - 種の切替は**網を残したまま**数字だけ変わる → 網が別の形へ変身していくのが見どころ。
- 手：クリック＝餌、ドラッグ＝LURE（匂いの道を描く・約7秒で消える）／CUT（網を切る・数秒で治る）。Shift で反転、`X` で切替。
- 証明：SNIFFERS（36体の「鼻」＝3本のセンサーと、いま選んだ方を rouge で表示）＋ RULE 欄の **ONE AGENT** バー（左・前・右の匂いと、次の判断 ◀ ▲ ▶ ?）。

## 検証のやり方（Browser ペインが非表示でも絵を確かめる）
- HTML から `/*SIM-BEGIN` と `/*SIM-END*/` の間を切り出し、Node の `require('vm').runInThisContext(src + ';globalThis.S={...}')` で読み込む → 回して RGBA を書き出し → Python(PIL) でコンタクトシート化 → Read で見る。
- ⚠️ `eval` で読むと**約15倍遅い**（sloppy モードの eval スコープで最適化が効かない。EE-03 で 22ms/歩 vs 1.5ms/歩）。必ず `vm` を使う。
