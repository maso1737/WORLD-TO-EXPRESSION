## SP-05 CHLADNI — 本体 `sound-patterns/05_chladni.html`＋法則 `_law/sp05_law.js`

- 流れ：法則の正本を Claude が書いて Node で実測 → 本体は Codex astra high（8.3 万トークン・1 ファイルだけ）→ Claude がブラウザで確認・2 か所直した。
- 法則（模様の型だけ借りた近似）：φ = cos(nπx)cos(mπy) ± cos(mπx)cos(nπy)、固有振動数 ∝ n²+m²（± の分裂 3.5%・個体差 1.2%×(m−n)）。
  候補 90 個から「隣と 4% 以上離れたもの」だけ残して **45 個の共鳴**（35〜7176 Hz）。近すぎる組を残すと 2 つの模様が混ざって読めない。
- 砂：加速度 DRIVE·|A| が 1（重力）を超えた所の粒だけ、(acc−1) に比例した距離をでたらめな向きに跳ぶ。**勾配の力は入れていない**のに節線に集まる（拡散の速さが場所で違うと、遅い所に溜まる）。

### 計算でわかったこと
- 正規化は最大でなく **RMS** でそろえる：低いモード（例 (1,2)+）は角だけ大きく揺れて中が静かなので、最大でそろえると中の砂がほとんど跳ばなかった。
- 共鳴ぴったり・DRIVE 12：2 秒で砂の 93〜97% が節線の帯へ（ばらまき直後は 21〜26%）。共鳴と共鳴の真ん中では 8 秒たっても 26%＝**形にならない**。30 セントずれると 0.38 止まり。
- 音（OfflineAudioContext）：共鳴ぴったりは真ん中の **3.67 倍**の RMS。
- **DRIVE が弱いと（8 未満）**、止まる帯（|A|<1/DRIVE）が広すぎて砂は節線でなく**帯のふちに二重線**で溜まる → 幅を 8〜24 に。
- **DRIVE が強いと（16 より上）**、線が**ちぎれて点の列**になる：となりの共鳴が少し混ざるので節線の上も完全には止まっておらず、本当に止まる点だけに集まる。説明文をこの内容に直した（「強いほど細い」は誤りだった）。

## その3 — SP-04 STANDING WAVE 本体 `sound-patterns/04_standing_wave.html`＋法則 `_law/sp04_law.js`

- ユーザー：SP-05 LP「良い感じ」→ コミット（689a53d・未 push）→ 次へ。Codex は別の発注で使い切ったかもしれない → 以後は Claude のサブエージェントで。
- 流れ：法則は Claude が書いて Node と OfflineAudioContext で実測 → 本体はサブエージェント（Opus）→ Claude がブラウザで確認・法則を 3 か所直した。
- 法則：理想の弦（両端固定）fₙ＝n·110 Hz。揺らし方はどの振動にも同じ強さ。指で軽く押さえる＝押さえた点で動こうとする振動ほど強く止める（∝ sin²(nπ·xt)）。はじく＝xp 0.2 を三角形に引いて放す。

### 計算でわかったこと（法則の直し 3 つ）
- **外れても「動かない点」はできる**：揺らされた弦はその高さなりの形で揺れるので、節の有無は境界にならない。違いは**揺れの大きさ**（Q 200 で、2 つの共鳴の真ん中は 0.013〜0.082＝共鳴の 1〜8%）と**形の純度**（共鳴 1.00 ⇄ 真ん中 0.43〜0.64）。READOUT は純度にした。
- **r² を落とすと弦にさざ波**：振れ（変位）は (1/ω²)·r²H。r² を落として H/Q にしていたら、高い振動がみな 1/Q ずつ残って 110 Hz の弦がさざ波になった → r²H/Q に直した（高い振動は 1/n² で小さくなる）。
- **Q 60 だと高い振動の節が止まりきらない**：共鳴でも下の振動が m/Q ほど混ざり、n=9 で節 7/8、n=12 で 8/11 → Q 200 で全部立つ（n=16 まで 15/15）。共鳴の幅は約 ±4 セントになったので、振動数スライダーを 4000 段（約 1.5 セント）にした。
- はじいた音で押さえると、残る振動は開放弦の 1/16 の音量しかなかった → 生き残る振動だけで音量をそろえる自動ゲイン（RMS 0.08〜0.10・開放弦 0.076）。本物のハーモニクスはもっと小さい音、と law に注記。
