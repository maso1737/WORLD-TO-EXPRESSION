## 🔧 環境の落とし穴（毎回ハマるので必読）

### Browser ペインは `document.hidden=true` → **rAF が止まる**
canvas アニメが自走せず、`screenshot` も timeout する。
- **draw-on-demand なページ**（07, l4-04, l3-08）はそのまま JS 実行で検証できる。
- **rAF 常時駆動なページ**（06 など）は、一時的に `window.__hook = { tick, draw, ... }` を仕込んで
  **`tick(ts)` を手動ステップ**して検証 → **検証後にフックを必ず除去**する。

### 検証は「ピクセル実測」が確実
DOM に出ない canvas の状態は、`getImageData` で
- 輪郭 x 座標の走査（07 のミラー連動＝左34/右34..0 を実証）
- lime ピクセル数（l4-04 の手がかり消失 1292→0 を実証）
- フレーム間ハッシュ差分（06 の FREEZE 静止、l4-04 のリシャッフル）
で数値化する。**ただし chaos/failure 時の「ステージ外周の破線枠」を拾って誤判定する**ので走査範囲を内側に絞ること。

### プレビューサーバ
`.claude/launch.json` に `static`(8123) と **`static2`(8125)** がある。
8123 が別チャットに occupied されることがあるので、その場合は `static2` を使う。
`python -m http.server` は PORT 環境変数を読まないため `autoPort` は効かない。
⚠️ **作業フォルダが `Projects` ルートのときは、この vault の launch.json は引けない**（ルートの
`Projects/.claude/launch.json` が使われ、`stage-link`(8000) と衝突する）。その場合はルート側に追加済みの
**`wte`(8126)**（`--directory` で vault を配信）を使う。

### `const ACC` は L3 ページにしか無い
lime 定数 `ACC` を宣言しているのは L3 の8ページだけ。**L2 で参照すると ReferenceError**。
しかも条件分岐の中（例: フラッシュ発火時）だと**その瞬間まで発覚せず、rAF ループごと落ちる**ので
「アニメーションが二度と動かない」という無関係な症状に見える（l2-05 で実際に踏んだ）。

### ボトムバーは5列グリッド固定
`#bottombar{grid-template-columns:auto auto auto 1fr auto}`。**セルを足すと6個目が2行目に折り返す。**
共通規約でも bottombar 構造の変更は禁止なので、**表示を足すなら既存セルの中に入れる**。

### コンソールのエラーはリロードしても消えない
`read_console_messages` はナビゲーションを跨いで蓄積する。**修正後もエラーが残って見えるので、
報告された行番号を現在のファイルと突き合わせて古い記録かどうか判定する**こと（l3-01 で実際に踏んだ）。

### `file://` で開くと静的スナップショットになる
Browser ペインで `file://` を開くと JS が動かない。**必ず localhost 経由**で開くこと。
